# Projeto: Construindo DBs com SqlAlchemy
Conjunto de programas que definem e constroem bancos de dados SQLite com SqlAlchemy.

O ultimo programa (main.py) foca na criação de duas tabelas relacionadas, Produto e Fornecedor, utilizando SQLAlchemy. Cada produto tem um fornecedor associado, demonstrando o uso de chaves estrangeiras para estabelecer relações entre tabelas.
